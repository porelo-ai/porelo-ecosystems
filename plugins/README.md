# Plugins

One plugin per build tool, each found by Porelo at run time.

- [maven](maven/README.md) - Maven, the first to be built; a native executable behind the contract.
- [gradle](gradle/README.md), [npm](npm/README.md), [pip](pip/README.md), [flutter](flutter/README.md) - not begun.
- [shared](shared/README.md) - what the plugins share.
